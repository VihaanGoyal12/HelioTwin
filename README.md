# 🌞 HelioTwin

**Making Sunlight a Measurable Urban Resource**

HelioTwin is an Urban Sunlight Intelligence Platform that helps planners, architects, and municipalities understand how sunlight interacts with buildings and public spaces throughout the day.

Instead of simply visualizing shadows, HelioTwin transforms sunlight into actionable planning insights that support sustainable urban development.

---

## Features

- Interactive city map visualization
- Study area selection
- Real-time sunlight and shadow analysis
- Environmental insights
- Planning scenario comparison
- Professional planning reports
- Browser-based GIS interface

## Vision

Modern cities already have digital layers for roads, traffic, and infrastructure.

HelioTwin introduces another missing layer:

**Sunlight Intelligence.**

Our goal is to help urban planners make more informed planning decisions using sunlight exposure as a measurable environmental resource.
